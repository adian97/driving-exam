# Driving Exam Website

This website has exactly two categories: Category A and Category B.

- `data/category_a.json`: first 45 questions
- `data/category_b.json`: remaining 45 questions
- Total: 90 questions

All questions are kept in their original order. Existing images and website design are retained.

## Publish on GitHub Pages

Upload the contents of this project folder to your repository's main branch, keeping the folder structure. The `index.html` file must be in the repository root.
